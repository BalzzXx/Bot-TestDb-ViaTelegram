## 📖 Tentang Project

**Telegram Register Bot** adalah bot Telegram berbasis Node.js yang memungkinkan user melakukan **registrasi mandiri** langsung dari chat. Data user (nama, nomor HP, email) tersimpan rapi di database MySQL.

Cocok untuk:
- 🎫 Sistem pendaftaran event / komunitas
- 🛒 Bot verifikasi pelanggan toko online
- 📋 Pengumpulan data member / user
- 🎓 Registrasi peserta workshop / kelas
- 🔐 Gate verifikasi sebelum akses fitur lain
